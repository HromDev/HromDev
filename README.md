## 🚀 О себе

Пишу продакшн-бэкенды на **PHP / Laravel / MySQL**, ботов для **Discord, Telegram и VK** на Python, нативные приложения на **C++ и Rust (Tauri)**, а также инструменты для игровых серверов: плагины, панели администрирования, логи, статистику и мониторинг. Фронтенд — когда нужно: **React, Vue, TypeScript**.

Моё портфолио оформлено как редактор кода в стиле VS Code: проводник проектов, вкладки, поиск и фильтры по технологиям, галерея скриншотов в каждом проекте.
